# Kiểm thử trình duyệt

Playwright đã được cấu hình cho desktop và mobile Chromium. Luồng kiểm tra đầu tiên xác minh tạo nhân vật và tải lại save của bộ khung. Các luồng ngày/sự kiện và offline sẽ được bổ sung khi có chức năng tương ứng.

Chạy `npx playwright install chromium` một lần, sau đó `npm run test:e2e`.
