# Tạo nhân vật

Form React chọn tên, avatar, hoàn cảnh và mục tiêu. Submit chuyển `CharacterConfig` tới `GameSession`; component không khởi tạo hoặc lưu state trực tiếp.

Ba hoàn cảnh dùng chung preset gameplay trong bộ khung. Các con số ở dashboard là giá trị thử nghiệm, chưa được cân bằng cho vòng chơi 30 ngày.
