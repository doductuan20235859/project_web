# Dashboard

Hiển thị snapshot đã được ứng dụng lưu thành công: ngày, nhân vật, cash, lương chờ nhận, khoản chưa trả, chỉ số và quan hệ từng NPC.

Bộ khung hiện khởi tạo được ngày 1 và mở lại tiến trình. Chưa có vòng thực hiện hoạt động, chuyển ngày hoặc xử lý sự kiện. Bổ sung các tương tác này qua command của engine, không tính luật trong component.
