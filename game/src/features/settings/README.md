# Cài đặt lưu trữ

Vị trí dành cho `SaveSettings`: xuất/nhập JSON, khôi phục backup và trạng thái cập nhật offline. Chỉ gọi use case ở application và trình bày phản hồi.

Việc thay tiến trình đang tồn tại cần có thao tác rõ ràng và giữ bản lưu trước; giao diện bộ khung chưa cung cấp reset hoặc import.
